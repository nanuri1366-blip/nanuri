3. **Supabase 클라이언트 고도화**:

   - 우측 사이드바: 최근 변경 내역(재고 기록) 리스트, 클릭 시 수정/삭제 팝업
5. **관리자 페이지 개편 (`app/admin/`)**:

## [2026-09-10] 관리자/생산자 UI/UX 개선 및 세부 구성/주문단가/랜딩 설정 기능 고도화

- **작업자**: Antigravity Pair Programmer
- **요청 사항**:
  1. 관리자 및 생산자 페이지 항목 순서 통일 ('설정순 (기본)' 옵션 추가 및 탭/사이드바 순서 통일)
  2. 랜딩 페이지 사진 바꾸기 기능 추가 (공지 팝업, 메인 히어로, 브랜드 스토리, 4종 세트 카드 이미지 URL 및 PC 로컬 파일 직접 업로드 지원)
  3. 재고량 칩 형태/배경색/여유·주의 기준 제거 및 크고 명확한 볼드 텍스트 표시
  4. 각 항목 세부 구성(완제품 세트 구성 상품 및 수량, 상품 내 원재료 배합) 팝업 내 동적 수정/추가/제거 지원
  5. 주문 내역에 현재 상품가가 아닌 주문 시점 단가(`unit_price`) 및 총액(`total_price`) 영구 고정 보존
  6. 단가 계산기 원재료 투입 항목명 및 단위를 DB와 독립적으로 자유롭게 직접 수정 가능하도록 개선
  7. 생산자 페이지 상단 1(원재료)/2(상품)/3(완제품) 탭 분리, 우측 상단 [작업 내역 일괄 저장] 버튼 배치, 항목별 수정 버튼 시각성 대폭 강화
  8. 변경 완료 후 GitHub 커밋 및 Vercel 배포

### 세부 작업 내역
1. **재고량 표시 컴포넌트 개선 (`components/common/StockBadge.jsx`)**:
   - 기존 알록달록한 배경색 칩, dot 아이콘, `(여유/주의)` 상태 라벨 완전 제거
   - `15px 800 (Bold)` 크기의 깔끔하고 가독성 높은 텍스트(`{수량} {단위}`)로 개편
2. **리스트 정렬 통일 (`components/common/DataTable.jsx`)**:
   - `_order` 또는 `default` 정렬 키 선택 시 배열 원본 순서(설정순)를 보존하도록 정렬 엔진 보완
   - 완제품, 상품(낱개), 원재료 테이블의 정렬 옵션 최상단에 `설정순 (기본)` 배치
3. **주문 시점 단가 고정 (`supabase_schema.sql`, `lib/inventoryCommon.js`, `app/admin/page.js`)**:
   - `orders` 테이블에 `unit_price`, `total_price` 필드 추가
   - 신규 주문 등록 및 수정 시 품목 선택 시 기본 단가 자동 채움 + 할인 등 수기 조정 지원
   - 과거 내역 조회 및 합계 금액에 고정 주문 단가 반영
4. **완제품/상품 세부 구성 동적 편집 (`app/admin/page.js`)**:
   - 완제품 수정 팝업: 포함 상품 선택, 수량 입력, 추가, 수량 변경, 삭제 기능 완비
   - 상품 낱개 수정 팝업: 포함 원재료 선택/직접 입력, 추가, 삭제 기능 완비
5. **단가 계산기 독립화 (`app/admin/page.js`)**:
   - 원재료 투입 항목명 및 단위를 자유롭게 수정 가능한 인풋 필드로 제공
   - '원재료 투입 추가' 클릭 시 새로운 커스텀 항목이 즉시 추가되어 DB와 독립적으로 시뮬레이션 가능

   - 공지 팝업, 메인 히어로 배너, 브랜드 스토리, 든든/실속/미니/낱개 4종 세트 이미지 수정 지원

   - 우측 상단에 `작업 내역 일괄 저장` 버튼 배치하여 탭을 오가며 입력한 내역을 누적하여 일괄 저장 가능
